# 사업장 미니 PC 서버 설치·이전 설명서

정비소 안에 둔 미니 PC(ASUS NUC 14 Essential 팬리스 NUC14MLK15, 메모리 8GB, SSD 2TB)를 앱의 **실제 운영 서버**로 만드는 순서입니다. 위에서부터 차례로 따라 하시면 됩니다. 명령은 복사해서 붙여 넣기만 하면 됩니다.

## 전체 그림

```
직원 휴대폰·사무실 PC·손님 링크·통장 문자 전달 앱
        │  https://app.내도메인.com
        ▼
   클라우드플레어(무료, HTTPS 자물쇠·공격 막기)
        │  미니 PC가 먼저 바깥으로 연결해 둔 길(터널). 공유기 포트를 열지 않음
        ▼
   정비소 미니 PC ── 앱 · DB · 매일 백업 · 밤 9시 반 새 버전 확인
        │
        └─ 모니터: 켜면 앱 화면이 저절로 뜸
```

| 단계 | 하는 일 | 걸리는 시간 |
|---|---|---|
| 1 | 리눅스(Ubuntu 26.04.1 LTS) 설치 | 40분 |
| 2 | 서버 환경 설치(명령 한 줄) | 30분(대부분 기다림) |
| 3 | 인터넷 주소(도메인) 사서 연결 | 30분 |
| 4 | 켜면 앱 화면이 저절로 뜨게 | 5분 |
| 5 | 출퇴근 와이파이 설정 | 2분 |
| 6 | 데이터: 새로 시작(추천) 또는 테스트 서버에서 옮기기 | 5~20분 |
| 7 | 통장 문자 전달 앱 주소 바꾸기 | 5분 |
| 8 | 백업 디스크·정전 대비(UPS) | 20분 |

**준비물**: 다른 윈도우 PC, 8GB 이상 USB 메모리, 모니터·키보드·마우스, 공유기에 꽂을 랜선, 해외 결제 되는 카드(도메인 1년 약 1만5천 원). 권장: UPS(APC Back-UPS BX950MI-GR 같은 USB 연결형, 약 15만~18만 원), 백업용 USB 외장 SSD/HDD(500GB 이상).

---

## 1단계. 리눅스 설치

1. 윈도우 PC에서 <https://ubuntu.com/download/desktop> 에 들어가 **Ubuntu 26.04.1 LTS**를 내려받습니다(.iso 파일, 약 6GB).
2. <https://rufus.ie> 에서 Rufus를 받아 실행합니다. 장치에 USB, 부트 선택에 내려받은 .iso, 파티션 방식 **GPT**로 두고 [시작]. 묻는 창은 권장값(ISO 이미지 모드)으로 합니다. USB 안의 내용은 지워집니다.
3. 미니 PC에 USB·랜선·모니터·키보드·마우스를 꽂고 전원을 켜면서 **F2**를 여러 번 눌러 BIOS에 들어갑니다.
   - 전원(Power) 메뉴의 **After Power Failure를 Power On**으로 바꿉니다. 정전 뒤 전기가 들어오면 저절로 켜지게 하는 설정입니다. **꼭 하세요.**
   - Secure Boot는 켜진 그대로 둡니다.
   - **F10**으로 저장하고 나옵니다.
4. 다시 켜면서 **F10**을 여러 번 눌러 부팅 메뉴에서 USB를 고르고, 'Try or Install Ubuntu'를 고릅니다.
5. 설치 화면에서 고를 것:
   - 언어 **한국어**, 키보드 **한국어(101/104키 호환)**, 인터넷 **유선**
   - 'Ubuntu 설치' → 대화형 설치 → **기본 선택**
   - '서드파티 소프트웨어 설치'에 체크
   - 디스크: **'디스크를 지우고 Ubuntu 설치'**. 고급 기능의 **디스크 암호화는 쓰지 않습니다**(켜면 정전 뒤 켜질 때마다 암호를 쳐야 해서 혼자 다시 켜지지 못함).
   - 계정: 이름 `관리자`, 컴퓨터 이름 `abs-server`, 사용자 이름 **`abs`**, 비밀번호는 길게 정해 종이에 적어 둡니다. '로그인할 때 암호 요구'.
   - 시간대 **서울**
6. 끝나면 USB를 뽑고 다시 시작합니다. 로그인 후 '소프트웨어 업데이터'가 뜨면 업데이트합니다.

> 팁: 공유기 관리 화면에서 미니 PC에 **고정 내부 IP(DHCP 예약)**를 걸어 두면 나중에 관리하기 편합니다(필수 아님).

## 2단계. 서버 환경 설치(명령 한 줄)

1. 미니 PC에서 **Ctrl + Alt + T**를 눌러 터미널(검은 창)을 엽니다.
2. 아래 한 줄을 복사해 붙여 넣고(터미널에서는 **Ctrl + Shift + V**) Enter를 누릅니다.

   ```sh
   bash <(wget -qO- https://raw.githubusercontent.com/heoyoungtae/Auto_Body_Shop/claude/project-thread-asspnw/deploy/minipc/install.sh)
   ```

3. 묻는 것에 답합니다.
   - 처음에 **이 PC 로그인 비밀번호**(입력해도 화면에 안 보이는 것이 정상)
   - 앱에서 쓸 **대표 아이디·이름·비밀번호**(앱에 처음 들어갈 계정. 나중에 앱에서 바꿀 수 있음)
4. 스크립트가 알아서 하는 일: 기본 도구 설치, 시간대 서울, 절전 끄기, 보안 업데이트 자동(필요하면 새벽 4시 재시작), 도커 설치, 앱 코드 내려받기, 비밀값(.env) 만들기, 앱 만들기·실행, 매일 03:00 백업과 21:30 새 버전 확인 등록.
5. 끝나면 화면에 **백업 암호**가 나옵니다. **종이에 적어 금고 같은 곳에 보관하세요.** 이것을 잃으면 백업을 열 수 없습니다.
6. 미니 PC의 웹 브라우저에서 <http://localhost:3000> 이 열리고 3번에서 정한 대표 계정으로 로그인되면 성공입니다.

중간에 멈추거나 빨간 글씨가 나오면 화면을 사진 찍어 Claude에게 보여 주세요. 같은 명령을 다시 돌려도 됩니다(이미 된 단계는 건너뜀).

## 3단계. 인터넷 주소(도메인) 연결

밖(휴대폰 데이터, 손님 견적 링크, 통장 문자 전달 앱)에서 들어오려면 주소가 있어야 합니다. **클라우드플레어 터널**을 쓰면 공유기 설정이나 고정 IP 없이, 무료로 HTTPS가 붙습니다.

**3-1. 클라우드플레어 가입·도메인 사기**

1. <https://dash.cloudflare.com/sign-up> 에서 가입합니다(이메일·비밀번호).
2. 왼쪽 메뉴 **Domain Registration → Register Domains**에서 원하는 이름을 검색해 삽니다. 예: `myshop-auto.com`(.com 1년 약 1만5천 원, 매년 자동 갱신).
   - **.kr 도메인(예: `jmotors.kr`)은 클라우드플레어에서 팔지 않습니다.** 가비아(gabia.com) 같은 국내 등록 업체에서 사고, 클라우드플레어 첫 화면 **'Add a domain'(도메인 추가)**에 넣어 무료(Free) 요금제를 고릅니다. 클라우드플레어가 알려 주는 네임서버 두 개(`○○.ns.cloudflare.com`)를 가비아 **My가비아 › 도메인 관리 › 네임서버 설정**에 넣으면, 몇 분~몇 시간 뒤 클라우드플레어에 '활성(Active)'으로 뜹니다.
   - 가비아에서 살 때 웹호스팅·메일·SSL 같은 추가 상품은 필요 없습니다(체크 해제). 정보 공개 대행(개인정보 보호)은 켜 두세요.

**3-2. 터널 만들기**

1. 왼쪽 메뉴 **Zero Trust**에 들어갑니다(처음이면 팀 이름을 정하고 **Free** 요금제를 고릅니다. 카드 등록을 물을 수 있지만 무료 요금제는 청구되지 않습니다).
2. **Networks → Tunnels → Create a tunnel → Cloudflared** 를 고르고 이름을 `abs-server`로 정합니다.
3. 설치 방법 화면에서 **Docker**를 누르면 `docker run ... --token eyJ...` 같은 긴 명령이 나옵니다. **그 줄 전체를 복사**해 둡니다(미니 PC에 직접 붙여 넣지는 않습니다).
4. 다음 화면 **Public hostname(또는 Published application routes)** 에서:
   - Subdomain `app`, Domain 3-1에서 산 도메인
   - Service Type **HTTP**, URL **`app:3000`**
   - 저장합니다.

**3-3. 미니 PC에 연결**

미니 PC 터미널에서:

```sh
bash ~/auto-body-shop/deploy/minipc/connect.sh
```

앱 주소(예: `app.myshop-auto.com`)와 3-2에서 복사한 줄을 붙여 넣으면 됩니다. "연결됨"이 나오면 휴대폰 **데이터(와이파이 끄고)**로 `https://app.myshop-auto.com` 을 열어 확인하세요.

## 4단계. 켜면 앱 화면이 저절로 뜨게

```sh
bash ~/auto-body-shop/deploy/minipc/screen.sh
```

- '앱 화면'이라는 별도 계정을 만들어, 켜면 그 계정으로 저절로 들어가 앱을 전체 화면으로 띄웁니다. 관리자 계정(abs)과 분리되어 있어 직원이 서버 설정을 건드릴 수 없습니다.
- TV 현황판을 띄우고 싶으면 설정 › TV 현황판의 연결 링크를 뒤에 붙입니다: `bash ~/auto-body-shop/deploy/minipc/screen.sh '현황판 링크'`
- 관리 작업을 할 때는 **Ctrl+Alt+Delete → 로그아웃 → '관리자'로 로그인**합니다.
- 끄기: `bash ~/auto-body-shop/deploy/minipc/screen.sh off`
- 인터넷이 끊겨 있으면 이 PC 안 주소(localhost)로 열려, 미니 PC 화면에서는 계속 쓸 수 있습니다.

## 5단계. 출퇴근 와이파이 설정

서버가 정비소 안에 있으므로 더 쉬워졌습니다.

1. 앱에 대표로 로그인 → **설정 › 출퇴근 장소(와이파이)**
2. **'서버(미니 PC)와 같은 정비소 인터넷이면 허용'**에 체크하고 저장합니다.

이제 정비소 와이파이에 연결한 휴대폰만 출퇴근을 누를 수 있고, 인터넷 회사가 정비소 주소(공인 IP)를 바꿔도 앱이 저절로 따라갑니다. 고정 IP를 신청할 필요가 없습니다.

- 확인: 휴대폰 와이파이를 끄고 데이터로 출근을 눌러 막히는지 봅니다.
- 와이파이인데도 막히고, 안내에 나온 '지금 주소'가 `2001:` 처럼 콜론(:)이 들어간 주소면 그 주소를 아래 칸에 넣어 함께 저장하고 Claude에게 알려 주세요.

## 6단계. 데이터: 새로 시작할까, 옮길까

**추천: 새로 시작.** 지금 테스트 서버에는 시연 계정(owner·manager… 비밀번호 demo1234)과 연습으로 넣은 가짜 고객·견적이 섞여 있습니다. 2단계에서 대표 계정 하나만 있는 깨끗한 상태로 시작했으니, 실제 사업장 정보·직원·거래처를 미니 PC 앱에 새로 넣으시면 됩니다.

테스트 서버에서 설정을 많이 해 두어 그대로 가져오고 싶으면 옮길 수 있습니다. **미니 PC의 지금 내용은 지워지고 테스트 서버 내용으로 바뀝니다.**

1. 오라클 서버를 만들 때 받은 **SSH 개인 키 파일**(예: `ssh-key-2026-11-08.key`)을 USB 등으로 미니 PC의 '다운로드' 폴더에 넣습니다.
2. 터미널에서(파일 이름은 실제 이름으로):

   ```sh
   bash ~/auto-body-shop/deploy/minipc/move-from-oracle.sh 150.230.58.33 ~/다운로드/ssh-key-2026-11-08.key
   ```

3. 옮긴 뒤에는 테스트 서버의 계정으로 로그인합니다. **설정 › 로그인 계정에서 시연 계정(manager·advisor·tech1·tech2·quality·safety·account)을 '계정 잠그기'**하고, owner 계정은 대표가 쓰되 비밀번호를 바로 바꾸세요(demo1234는 공개된 비밀번호입니다).

## 7단계. 통장 문자 전달 앱 주소 바꾸기

통장·카드 문자 전달을 이미 설정했다면 주소가 바뀌었으므로, 앱 **통장·카드 내역 › 설정**(메뉴 찾기 칸에 '통장')에서 새 전달 주소를 확인해 휴대폰의 문자 전달 앱(또는 아이폰 단축어)에 다시 넣습니다. 처음 설정하는 것이면 설정 화면의 설명서대로 하시면 됩니다.

## 8단계. 백업·정전 대비

**저절로 되는 것**

- 매일 03:00 DB(14일치)와 사진 묶음(최근 3개)을 암호화해 미니 PC 안 `~/backups`에 둡니다. 결과는 앱 알림으로 오고, 실패하면 대표에게 알림이 갑니다.
- 새 버전을 올리기 직전에도 DB를 따로 백업합니다(30일치).

**8-1. 백업 디스크(강력 추천)**

미니 PC SSD가 고장 나면 안의 백업도 같이 잃으니, USB 외장 디스크에도 복사합니다.

1. 외장 디스크를 꽂고, 프로그램 목록에서 **'디스크'**를 엽니다.
2. 왼쪽에서 외장 디스크를 고르고 → 오른쪽 위 ⋮ → **디스크 포맷**(안의 내용은 지워짐) → 그다음 + 로 파티션을 만들 때 **볼륨 이름 `ABS-BACKUP`**, 형식 **Ext4**로 합니다.
3. 터미널에서:

   ```sh
   bash ~/auto-body-shop/deploy/minipc/backup-disk.sh
   ```

   이제 매일 외장 디스크에 DB(60일치, 암호화)를 복사하고, 사진은 `files` 폴더에 **바뀐 것만** 더합니다(앱에서 지운 사진도 남아 있음). 1TB면 몇 년 쓸 수 있고, 남은 공간은 백업 결과 알림에 나옵니다. 디스크를 빼 두면 '백업 디스크 없음'이 뜹니다.
   - 용량: **외장 SSD 1TB** 추천(삼성 T7·샌디스크 익스트림 등). 외장 HDD 2TB도 괜찮지만 충격에 약합니다.
   - 사진 폴더는 암호화되지 않으니 디스크는 잠금장치가 있는 곳에 보관하세요.

**8-2. 바깥 보관(권장)**

불이나 도난에 대비해 하루 한 번 정비소 밖에도 둡니다. 테스트 서버를 쓰던 오라클 계정의 무료 저장소(20GB)를 그대로 쓸 수 있습니다.

1. 오라클 클라우드 → Storage → Buckets → Create Bucket(이름 `abs-backup`).
2. 버킷 → **Lifecycle Policy Rules → Create**: 14일 지난 파일 삭제(무료 20GB 넘지 않게). DB는 매일, 사진 묶음은 일요일에만 올라갑니다.
3. 버킷 → **Pre-Authenticated Requests → Create**: 대상 Bucket, 'Permit object writes', 만료 1년 뒤. 만들어진 주소(끝이 `/o/`)를 복사합니다.
4. 미니 PC 터미널에서(따옴표 안에 주소를 붙여 넣기):

   ```sh
   printf 'BACKUP_PAR_URL=%s\n' '복사한주소' | bash ~/auto-body-shop/deploy/set-env.sh
   ```

> 사진 묶음이 5GB를 넘으면(백업 결과 알림의 '파일' 크기) 바깥 보관 방법을 바꿔야 하니 Claude에게 말씀해 주세요.

**8-3. 정전 대비(UPS)**

1. 미니 PC를 UPS의 배터리 콘센트에 꽂고, UPS의 USB 선을 미니 PC에 꽂습니다. 공유기도 UPS에 꽂으면 짧은 정전 중에도 접속이 유지됩니다.
2. 터미널에서:

   ```sh
   bash ~/auto-body-shop/deploy/minipc/ups.sh
   ```

정전이 길어지면 배터리 40%(또는 남은 시간 5분)에서 PC가 안전하게 꺼지고, 전기가 돌아오면 저절로 켜집니다(1단계 BIOS 설정 덕분). UPS가 없어도 앱은 다시 켜지면 저절로 살아나지만, 꺼지는 순간 저장 중이던 내용이 깨질 수 있어 UPS를 권합니다.

**8-4. 복구 훈련(석 달에 한 번)**

```sh
cd ~/auto-body-shop/deploy && ls ~/backups | tail -3
sudo bash restore.sh ~/backups/db-(날짜).sql.gz.enc
```

## 새 버전은 어떻게 올라가나요

- Claude가 만든 변경을 GitHub에서 병합하면 **곧바로 테스트 서버**(오라클)에 올라가고, **미니 PC는 그날 밤 21:30에** 새 버전을 확인해 올립니다. 올리기 전에 DB를 백업하고, 새 버전 만들기가 실패하면 이전 버전을 그대로 씁니다. 바꿔 끼우는 동안 몇 초 끊깁니다.
- 지금 바로 올리고 싶으면 미니 PC 터미널에서: `sudo bash ~/auto-body-shop/deploy/minipc/update.sh`
- 기록: `tail ~/update.log`

## 테스트 서버(오라클)는 계속 둘까요

**계속 두는 것을 추천합니다.** 무료이고, 낮에 병합한 변경을 먼저 테스트 서버에서 눌러 보고 이상하면 밤 9시 반 전에 Claude에게 알려 되돌릴 수 있습니다. 시연 계정이 있어 직원 교육용으로도 좋습니다. 단, **테스트 서버에는 실제 고객 정보를 넣지 마세요**(해외 서버이고 시연 비밀번호가 공개되어 있음). 오라클은 오래 안 쓰는 무료 서버를 회수할 수 있는데, 회수되더라도 운영에는 영향이 없습니다.

## 자주 쓰는 명령(관리자 abs 계정 터미널)

```sh
cd ~/auto-body-shop/deploy
sudo docker compose ps                      # 상태(모두 running 이면 정상)
sudo docker compose logs --tail 50 app      # 앱 기록
sudo docker compose logs --tail 20 tunnel   # 인터넷 주소 연결 기록
sudo docker compose restart app             # 앱 다시 켜기
tail ~/backups.log ~/update.log             # 백업·업데이트 기록
df -h /                                     # 디스크 남은 공간
```

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 밖에서 주소가 안 열림, 미니 PC 화면에서는 열림 | 정비소 인터넷 연결, `sudo docker compose logs --tail 20 tunnel` |
| 미니 PC 화면에서도 안 열림 | `sudo docker compose ps`, 안 되면 PC 재시작 |
| 출근 단추가 '정비소 인터넷에서만' 이라며 막힘 | 휴대폰이 정비소 와이파이에 연결되었는지, 5단계 체크 |
| 백업 실패 알림 | `tail ~/backups.log` |

화면 사진이나 명령 결과를 Claude에게 보여 주시면 원인을 찾아 드립니다.
